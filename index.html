about us

わたしたちのこと

鳥取県で活動している、夫婦フリーランスチーム「Hotta」です。
広告とデザイン、ふたつの専門性を、ひとつの窓口でお届けしています。

— husband / marketer
Hotta.S

マーケティング歴6年、Meta広告運用を中心に、 累計売上3.5億円規模の広告アカウントを担当してきました。 LINE構築や、AIを活用した24時間自動監視・自動応答など、 「数字をつくる」仕組みづくりが得意です。

Meta広告 Google広告 LINE構築 Notion構築 AI 24時間監視 自動化設計 分析・改善
— wife / designer
Hotta.A

Webデザインを軸に、SNSコンテンツの制作・運用まで担当。 広告の「クリエイティブ」と「世界観」を、 ターゲットに届く形に整えていきます。

01

Meta広告運用

Facebook / Instagram Ads

契約100件超・売上3.5億円規模の運用経験から、 広告 × LP × LINE を夫婦で一気通貫設計します。

対応できること
  • アカウント設計・初期構築
  • ターゲティング・配信設計の強化
  • バナー / A/Bテスト用クリエイティブ制作
  • コンバージョン設定・計測タグ実装
  • 既存広告アカウントの最適化
  • 運用代行（手数料制でスケーリング対応）
  • LP制作 / LINE導線まで連携対応
こんな方におすすめ

「初めてMeta広告を始めたい」「広告を回しているけど成果が出ない」「広告→LP→LINEまで一貫した導線を作りたい」月5万円〜の広告予算がある事業者の方など

02

LINE公式構築

LINE公式 / Lステップ / エルメ対応

「LINEを作る」のではなく「売上に直結するLINEを設計」。 広告 × デザイン × LINE構築を、夫婦チームで一気通貫対応します。

対応できること
  • LINE公式アカウント初期設定・プロフィール構築
  • リッチメニュー制作（最大6分割）
  • 挨拶・自動応答メッセージ設定
  • ステップ配信シナリオ設計（5通〜20通）
  • Lステップ／エルメ初期設定
  • 販売導線設計（集客 → 教育 → 販売）
  • タグ管理・顧客管理設計
こんな方におすすめ

「公式LINEを開設したけど何を設定すればいいかわからない」「LINEを作ったけど放置してしまっている」「LINEと広告を連携させたい」コーチ・コンサル・サロン・スクール経営者の方など

03

バナー制作

広告で反応が取れるバナー

ただ綺麗なだけじゃない、「広告で反応が取れる」バナーを。 Meta広告運用者 × Webデザイナーの夫婦チームで、 反応率の上がる構成・配色・コピーを1枚に凝縮します。

対応できること
  • ターゲットが指を止める1秒インパクト設計
  • コンバージョンに繋がる訴求文の優先順位
  • 媒体（Meta / LINE / Web）ごとの最適サイズ・余白
  • A/Bテスト用クリエイティブ制作
  • キャッチコピー考案・リサイズ展開
  • 最短2営業日のスピード納品
こんな方におすすめ

「バナーを作ってもクリックされない」「見た目だけで発注して成果に繋がらなかった」ToC商材を販売している方、SNS広告・LINE広告を回している方など

04

Notion構築代行

マーケ視点のNotion設計

「もう散らからない」業務に合わせたNotionをオーダーメイド構築。 スタートアップを年商5億に育てた現場の設計思想を、 あなたのビジネスに合わせて落とし込みます。

対応できること
  • 業務に合わせたページ・テンプレ設計
  • データベース構築・リレーション設定
  • 自動化設計（ボタン・テンプレ・自動入力）
  • マーケ視点での運用設計
  • 操作マニュアル（PDF）作成・運用レクチャー
  • 納品後のチャットサポート
こんな方におすすめ

「Notionを使いたいけど何から始めればいいかわからない」「自分で作ったけど散らかってしまう」「業務に合った仕組みが欲しい」個人事業主・フリーランス・スタートアップの方など

05

Notionレクチャー

60分マンツーマン

年商5億企業を支えたNotion術を、60分で凝縮してお伝えします。 「基本操作」だけでなく、マーケ視点で「成果につながる使い方」を、 あなたのビジネスに合わせて完全カスタマイズ。

対応できること
  • Notion基本操作（散らからない使い方の原則）
  • データベース・ページ設計の考え方
  • ご自身のビジネスへの応用方法
  • マーケ視点での活用アイデア
  • テンプレ・拡張のヒント
  • 事前ヒアリング + 画面録画の提供付き
こんな方におすすめ

「本やYouTubeで学んでもピンと来ない」「自分のビジネスに最適化したい」初心者〜既に使っているが活用しきれていない個人事業主・フリーランスの方など

06

AI活用のシステム開発

Web App / 業務自動化

「こういうものが欲しい」を、AIを使って動くシステムにします。 自社の業務のために20本以上つくってきた作り方を、そのままお渡しします。

対応できること
  • 業務用Webアプリ（見積・予約・進捗・在庫の管理など）
  • 手作業の自動化（集計・レポート作成・定期配信）
  • LINE Bot・チャットボットの制作
  • AIを使った業務支援（文字起こし・要約・書類作成・OCR）
  • Notion / スプレッドシート / 外部サービスとの連携
  • 業務のヒアリング → 要件整理 → 実装 → 公開まで一括
  • まず小さく作って試す、から始められます
こんな方におすすめ

「Excelと手作業で回していて限界」「開発会社の見積が高すぎて止まっている」「まず小さく試したい」「エンジニアに頼むほどでもない細かい仕組みが欲しい」という事業者の方など
